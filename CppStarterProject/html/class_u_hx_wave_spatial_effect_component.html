Detailed Description

An implementation of UHxSpatialEffectComponent that defines the Haptic Effect using a simple sine wave generator. The waveform starts at 0 then increases by default.

Field Documentation

◆ frequency_Hz_

float UHxWaveSpatialEffectComponent::frequency_Hz_

The frequency at which the signal repeats itself [Hz].

Changing this while the effect is playing can cause discontinuities.

◆ input_phase_offset_deg_

float UHxWaveSpatialEffectComponent::input_phase_offset_deg_

The phase at which the wave starts [deg], then continues from there.

For example: an offset of 90 degrees turns a sine wave into a cosine wave.
