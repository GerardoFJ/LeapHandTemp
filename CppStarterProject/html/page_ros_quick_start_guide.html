ROS Quick Start Guide

Start developing with the HaptX SDK. This page will guide you through setting up and using our nodes for ROS Noetic and ROS 2 Humble .

Software prerequesites

To use our ROS nodes you will need to install the appropriate version of ROS for Windows 10.

  • For ROS 1 Noetic follow the instructions for installing ROS on Windows .
  • For ROS 2 Humble follow the instructions for installing ROS 2 on Windows . Note that you will need to substitute "humble" for "foxy" in those instructions.

Running the ROS 1 version of the haptx_node

After following the above steps to install your ROS version and installing ROS in the Installation instructions, do the following to use the node.

  1. Open a terminal as described in the ROS installation instructions.
  2. Call the %HAPTX_SDK_HOME%\Plugins\ROS\Haptx\setup.bat file. You are now able to access the HaptX messages and node.
  3. Call rosrun haptx haptx_node to run the haptx_node.

Running the ROS 2 version of the haptx_node

After following the above steps to install your ROS version and installing ROS in the Installation instructions, do the following to use the node.

  1. Open a terminal as described in the ROS installation instructions.
  2. Call the %HAPTX_SDK_HOME%\Plugins\ROS2\Haptx\setup.bat file. You are now able to access the HaptX messages and node.
  3. Call ros2 run haptx haptx_node to run the haptx_node.
