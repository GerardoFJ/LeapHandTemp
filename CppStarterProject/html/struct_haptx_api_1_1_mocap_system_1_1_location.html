Detailed Description

Structure to represent information to locate a sensor's position and orientation.

Sensor location (positions and orientation) are reported with respect to the magnetic motion tracking transmitter. In other words, the source is position {0, 0, 0} and orientation {1, 0, 0, 0}. Refer to hardware documentation for a proper frame of reference diagram.
