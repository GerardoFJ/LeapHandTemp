Unreal Integration Guide

Follow these steps to add HaptX functionality to an existing project.

Software prerequisites

  • SteamVR
  • Unreal Engine version 4.23 or 4.27 (other versions are either untested or unsupported)
  • Microsoft Visual Studio 2019 with "Game development with C++" workload

Notes

If you're starting from scratch, we recommend using the pre-configured UnrealStarterProject instead.

Setup steps

  1. Convert the Unreal project to a C++ project if it is not already.
    • This can be done by generating an empty C++ class from the content browser.
  2. Make sure the Unreal project has the SteamVR plugin enabled.
  3. Copy the HaptX Unreal Plugin over to the project's Plugins directory.
    • If the directory does not exist, create it manually.
  4. Regenerate Visual Studio project files (from the context menu for the .uproject file in Windows Explorer).
    • See Figure 1 below for a screenshot.
  5. Open the Visual Studio project for the Unreal project.
  6. For C++ classes to link against HaptX classes, HaptX and/or HaptxPrimitives need to be added as module dependencies in the project's Build.cs file:
    PublicDependencyModuleNames.AddRange(new string[] {
    /*existing dependencies*/,
    "HaptX", "HaptxPrimitives"
    });
  7. For packaged builds of the project to work, HaptX needs to be added as a plugin in the project's .uproject file:
    "Plugins": [
    /*existing plugins*/,
    { "Name": "HaptX", "Enabled": true }
    ]
  8. Build the Visual Studio project.
  9. Open the Unreal project.
  10. The HaptX Unreal Settings window will open with a list of suggested changes to the Unreal project settings.
    • It is highly recommended to press "accept all" unless you have a strong reason not to.
  11. Enable showing plugin content in the content browser if it is not showing already.
    • This can be done by looking at the bottom right of the content browser and selecting View Options → Show Plugin Content from the menu.
    • See Figure 2 below for a screenshot.
  12. Expand the sources panel in the content browser (if it is collapsed), and click on haptx Content.
    • See Figure 3 below for a screenshot.
  13. Create child blueprints of haptx Content → HaptxCore_BP, HaptxHand_BP, and HaptxPawn and move them to the project's content folder.
  14. Configure the Haptx → Left Hand Class and Right Hand Class variables on the HaptxPawn child blueprint to spawn a HaptxHand_BP child blueprint.
  15. Add an instance of the HaptxPawn child blueprint to a level, or configure the game mode's Default Pawn Class to spawn the HaptxPawn child blueprint.
  16. Add an instance of the HaptxCore_BP child blueprint to a level and configure its Tactile Feedback Collision Types , Force Feedback Collision Types , and Grasp Collision Types fields to include the types of objects meant to elicit these responses.
  17. In the SteamVR plugin settings, regenerate the Steam VR Input action manifest and controller bindings
    • This is required for simulated input with VR controllers to function.
  18. You're ready to start developing with HaptX Gloves G1! Check out the Unreal Quick Start Guide.
