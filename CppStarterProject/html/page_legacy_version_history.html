HaptX SDK 2.0.0-alpha.0

July 20, 2020

First pre-release in the 2.x.y series.

This version of the SDK is marked by a significant transformation of the software architecture that borrows ideas from relational programming. Much of the system's state is now crystallized into discrete structures (frames) that are visible to the top-level application. Frames are produced, consumed, or manipulated by various stateless systems, frequently static functions, that are also made visible to the top-level application and produce few, if any, side effects. These changes result in a much more modular data flow relative to the older API, which had to be used a specific way and obscured data that external developers might have found useful. Our hope is that these changes not only enable but inspire creative applications of HaptX Gloves.

Several features have also been added or improved:

  • Addition: Multi-user support for game engine plugins
  • Addition: Support for HaptX proprietary magnetic motion capture technology
  • Addition: Programming interface for the Hardware State Visualizer (formerly the Intended State Visualizer)
  • Modification: Support for newer versions of Unreal Engine and Unity
  • Modification: Addition of a graphical interface to the User Profile Utility (formerly the User Hand Profile Utility)
  • Modification: C++ Starter Project improvements to demonstrate additional use cases
  • Modification: Removal of support for legacy motion capture technology
  • Documentation: Addition of multi-user guide
  • Documentation: Addition of system conventions guide
  • Documentation: General reorganization to make it easier to get started with the SDK
  • Documentation: Removal of obsolete content

This pre-release is not compatible with Air Controller hardware.
