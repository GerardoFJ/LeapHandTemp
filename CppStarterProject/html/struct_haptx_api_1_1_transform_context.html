Detailed Description

Names two coordinate systems, where the first, the "parent," represents some base reference frame and the second, the "child," represents a derived coordinate frame.

A TransformContext used in conjunction with a separately maintained Transform object offers a convenient means of identifying coordinate systems and the geometric link between them.
