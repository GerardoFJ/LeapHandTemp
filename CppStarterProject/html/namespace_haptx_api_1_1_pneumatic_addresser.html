HAPTXAPI_DLLEXPORT Result< PneumaticAddress > HaptxApi::PneumaticAddresser::findAddress ( const HaptxUuid & peripheral_id,
int port,
const Airpack & airpack )

Retrieves a PneumaticAddress that can be used to access a pneumatic pressure value in the given Airpack's PneumaticFrame.

The specific address corresponds to the provided Peripheral and port combination based on the SDK's notion of how the hardware represented by the Peripheral and Airpack is physically connected.

Parameters
peripheral_idThe ID of the Peripheral containing the port whose pneumatic address is sought.
portThe port whose pneumatic address is sought.
airpackThe Airpack associated with the PneumaticFrame the address indexes into.
Returns
The PneumaticFrame address at which a pressure value corresponding to the given port is stored in a PneumaticFrame for the given Airpack, or an error code.
