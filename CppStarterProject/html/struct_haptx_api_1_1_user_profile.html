Detailed Description

User-specific information that includes hand dimensions and aesthetic preferences.

Several locating features are provided relative to the hand's tracking origin (MCP3).

◆ mcp3_joint1_pos_offsets_m

Vector3D HaptxApi::UserProfile::mcp3_joint1_pos_offsets_m[RD_LAST][F_LAST]

The positional offset [m] from the tracking origin (MCP3) for joint 1 of each finger on each hand.

Note
These positions are relative to the ideal MCP3 as defined by hardware conventions, thus the positional offset in this array for MCP3 is the offset from the ideal position to the actual position.
