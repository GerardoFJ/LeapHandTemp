Mocap Visualizer

A discrete application that communicates the status of the magnetic motion capture system used by HaptX Gloves G1 to determine finger positions.

Function

The Mocap Visualizer is an executable that shows the status of the magnetic motion capture and tracking system used in HaptX Gloves G1.

The tool is a low-level application that can be used to confirm that hardware is functioning as expected.

Usage

  1. Attach the USB cord of one HaptX Glove to a USB port on your workstation or to a USB port on a HaptX Airpack (that is connected to your workstation via USB).
    Note
    The Mocap Visualizer will not function over a Wi-Fi connection.
  2. Start the Mocap Visualizer by executing %HAPTX_SDK_HOME%\Tools\HyleasVisualizer.exe , or from the HaptX Dashboard by selecting File → Launch Application → Mocap Visualizer .

User interface

Figure 1. Mocap Visualizer interface; X = Red, Y = Green, Z = Blue

Sensor and source display

The Mocap Visualizer displays the pose of all tracked sensors (small triads) relative to a motion capture datum (large triad). The datum is collocated with an electromagnetic element embedded in the Haptx Glove G1. Move the fingers of the glove to see their motions reflected in the visualizer.

As this tool displays motion capture within a glove, it is not suitable for monitoring gross-scale motion (i.e., the world position) of the glove that would be measured using a tracker.

System and sensor status

The status of the system appears in a terminal toward the upper left of the window. Information will appear in this terminal during routine usage. It will also detail errors should they occur.

The status of each sensor appears at the lower left of the window. A green indicator shows that a sensor is functioning normally.

Sensor pose values

The poses (translation and rotation) of all sensors relative to the motion capture origin appear at the lower left of the window.

  • Positions are shown as vectors with values in <x, y, z> order and units of meters.
  • Rotations are shown as quaternions with components displayed in <r, i, j, k> order.

Clicking the Copy button next to a sensor's pose information copies the information to the clipboard.

Sensor and source appearance

Individual sensors can be hidden by unchecking the Visible box next to their pose information. To replace triads with shapes resembling the hardware itself, check Render Hardware .

Rendering the other hemisphere

Check Render Other Hemisphere to place small, white spheres at locations corresponding to <-x, -y, -z> relative to the sensors' nominal origins. Each dot represents where a triad will be drawn when the state of the Inverted checkbox for that sensor changes. (See the Changing sensor hemispheres section below.)

Sensor pose transformations

Changing sensor hemispheres

To flip a sensor's pose about all planes, check the Inverted box corresponding to the sensor. This is purely a visual adjustment and does not alter the configuration of the motion capture system. This function is useful in the case that a sensor appears in the wrong location when the application starts.

Additional sensor visual offsets

To effect additional translational and rotational transformations on a sensor's pose, use the text inputs at the upper right of the window and click Apply . These adjustments are visual only. We recommend keeping these parameters at their default values in general.
