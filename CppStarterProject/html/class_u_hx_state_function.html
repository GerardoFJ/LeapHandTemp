Detailed Description

The base class for all custom state functions used in UHxConstraintComponents .

DO NOT INSTANTIATE THIS CLASS! Use a child class instead.

To implement a custom state function inherit from this class and override initialize(), and update().

See the Unreal Haptic Primitive Guide for a high level overview.
