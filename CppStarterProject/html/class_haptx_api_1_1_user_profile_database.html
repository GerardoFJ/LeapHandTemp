Detailed Description

Methods for creating and managing user profiles.

This interface operates using user profile files, which are encrypted and written to disk via addUserProfile(). After a profile has been written to disk, it can be loaded via getUserProfile(). The interface also maintains the notion of an "active user," which can be similarly set and retrieved using setActiveUsername() and getActiveUsername().

A user profile is considered a "demo profile" if the corresponding username begins with UserProfileDatabase::DEMO_USER_NAME_PREFIX. Such profiles are excluded by default in calls to getAllUsernames().

User profile files, and the notion of which user profile is the presently "active" one, are persistent across application executions.
