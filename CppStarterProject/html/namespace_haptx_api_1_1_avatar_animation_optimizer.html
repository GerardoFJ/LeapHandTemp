Interpolates between a user's profile and their associated avatar's profile based on how close to the thumb tip each fingertip is. The closer a fingertip is to the thumb tip the closer the output profile is to the avatar's profile.

Parameters
rel_dirWhich hand is being optimized.
user_profileThe user's real profile.
avatar_profileThe profile matching the user's avatar.
mocap_frameThe current mocap frame.
[in,out]out_optimized_profileUpdated with interpolated bone lengths & joint positions.
relative_distance_thresholdThe proportion of the distance between the user's index and thumb fingertips when they make an "L" shape with their hand at which interpolation toward the avatar profile begins. Valid between 0 and 1. A value of 0 effectively disables hand animation optimization and a value of 1 makes it engage as early as possible.
Returns
True if out_optimized_profile is successfully updated, and false otherwise.
