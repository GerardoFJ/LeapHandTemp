Detailed Description

Responsible for detecting and managing grasps with grasp-capable bodies and graspable objects and recommending actions to the game engine.

This class makes a distinction between bodies and objects. Bodies are physical bodies that are capable of grasping an object (fingers, hands, arms, etc.). Objects are physical bodies that are capable of being grasped (cell phones, coffee mugs, rocks, etc.). Game engines that intend to use the GraspDetector are expected to feed contact information about bodies and objects using GraspDetector::addGraspContact(), and call GraspDetector::detectGrasps() once all contact information for a period of time has been input. The GraspDetector will then append to the deque returned by GraspDetector::getGraspHistory() with recommendations to create, update, or destroy grasps along with information about which bodies and objects are involved. It's up to the game engine what to do with this information. For example, in the HaptX UnrealEngine plugin, UPhysicsConstraintComponents are created between bodies and objects involved in a grasp, updated when said grasp changes, and destroyed when the grasp no longer exists.
