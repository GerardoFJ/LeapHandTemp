void HaptxApi::VibroClip::combine ( const VibroClip & other,
float multiplier,
uint64_t start_point,
uint64_t duration )

Takes a number of samples from another clip, and adds them to current values in this clip, scaled by a given multiplier. An offset to the clip to add can be provided, and looping of the other clip will be accounted for. Note that this will not modify the looping flag of this clip, extending the clip if necessary.

Parameters
otherThe clip from which to take values.
multiplierA scalar multiplier applied to the amplitude of the other clip as it is combined.
start_pointThe index of the first vibro sample to read from the other clip.
durationThe number of vibro samples to read from the other clip.

static VibroClip HaptxApi::VibroClip::createLoopingSawtoothClip ( float frequency_hz,
float amplitude_m,
bool inverted )
static

Generates a looping Vibro clip containing a sawtooth wave. Frequency of the signal in the resulting clip may not exactly match the parameter due to numerical limitations associated with vibrotactile sampling rate. Long clips will be truncated at ten seconds and will not loop.

Parameters
frequency_hzThe frequency of one cylce of the sawtooth wave [Hz].
amplitude_mThe peak amplitude of the sawtooth wave (i.e. the point of the wave furthest from 0) [m].
invertedIf true, then the wave will instantly increase to amplitude, and gradually return to 0. Otherwise, the wave will gradually increase from 0 to the amplitude before instantly resetting to 0.
Returns
A looping Vibro clip containing a sawtooth wave.

Generates a looping Vibro clip containing a sine wave. Frequency of the signal in the resulting clip may not exactly match the parameter due to numerical limitations associated with vibrotactile sampling rate. Long clips will be truncated at ten seconds and will not loop.

Parameters
frequency_hzThe frequency of the sine wave [Hz].
amplitude_mThe peak amplitude of the sin wave (i.e., midpoint-to-peak) [m].
offset_mThe value around which the sin wave oscillates [m].
phase_degThe phase that the wave starts at [deg], then continues from there (i.e., 90 degrees turns a sine wave into a cosine wave).
Returns
A looping Vibro clip containing a sine wave.

static VibroClip HaptxApi::VibroClip::createLoopingSquareClip ( float frequency_hz,
float amplitude_m,
bool inverted )
static

Generates a looping Vibro clip containing a square wave. Frequency of the signal in the resulting clip may not exactly match the parameter due to numerical limitations associated with vibrotactile sampling rate. Long clips will be truncated at ten seconds and will not loop.

Parameters
frequency_hzThe frequency of one cycle of the square wave [Hz].
amplitude_mThe peak amplitude of the square wave (i.e., the height when it isn't 0) [m].
invertedIf true, then the wave will begin at the given amplitude, and then become zero halfway through the period. Otherwise, the wave will begin at zero before increasing to the amplitude halfway through the period.
Returns
A looping Vibro clip containing a square wave.
