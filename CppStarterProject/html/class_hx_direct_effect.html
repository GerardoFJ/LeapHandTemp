Detailed Description

The Haptic Effect component to override when creating effects that aren't convenient via the other base effect classes.

Extend this class and override the GetEffectMultiplier() function to create your own direct haptic effects. Add tactors to the effect using AddToTactor() or AddToCoverageRegion() and call Start() when ready.
