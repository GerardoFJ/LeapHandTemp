Detailed Description

An implementation of UHxObjectEffectComponent that defines the Haptic Effect using a simple sine wave generator. The waveform starts at 0 then increases by default.

◆ frequency_Hz_

float UHxWaveObjectEffectComponent::frequency_Hz_

The frequency at which the signal repeats itself [Hz].

Changing this while the effect is playing can cause discontinuities.

◆ input_phase_offset_deg_

float UHxWaveObjectEffectComponent::input_phase_offset_deg_

The phase at which the wave starts [deg], then continues from there.

For example: an offset of 90 degrees turns a sine wave into a cosine wave.
