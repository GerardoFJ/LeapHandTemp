Detailed Description

A generic HaptX peripheral that may contain motion-tracking and haptic-rendering components.

A Peripheral object is "real" in the case its Peripheral::is_simulated flag is cleared. Normally, a real Peripheral has a hardware analog that is in active use within a given session. The opposite of a real Peripheral is a "simulated" peripheral, which, as the name implies, does not have a hardware analog active in the current session.
