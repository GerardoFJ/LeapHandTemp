Detailed Description

The abstract Haptic Effect class to override when creating effects that are applied in free space.

To utilize this type of effect:

  1. Override the HaptxApi::SpatialEffect::getForceN() function
  2. Add tactors using HaptxApi::ContactInterpreter::registerSpatialEffect()
  3. Call HaptxApi::HapticEffect::start()
  4. Use HaptxApi::ContactInterpreter nominally
