◆ update()

int UHxNStateFunction::update ( float input_position)
overridevirtual

Updates the state.

State positions are sorted, so 0 always corresponds to positions lower than the smallest position, N-1 corresponds to positions higher than the largest position, and the rest of the states are sorted in-between. If invert_state_order_ is true, that is flipped. Will always output STATE_FUNCTION_INVALID_STATE if the array is empty.

Parameters
input_positionThe new position.
Returns
The index of the state position that is nearest the input position.
