Computes finger joint angles for an entire hand based on tracked fingertip locations.

Parameters
gloveWhich Glove to compute finger joint angles for.
mocap_frameExpected to contain fingertip locations relative to the middle finger metacarpophalangeal joint (MCP3) tracking origin. For any fingertip locations that are missing, the finger animation will be interpolated from nearby fingers that do have data, except for the thumb, which will be animated sticking straight out if it's missing data.
anim_profileUser profile data to inform animation calculations.
[in,out]anim_frameComputed joint angles are added to this AnimFrame.
Returns
True if joint orientations for each finger joint are inserted.
