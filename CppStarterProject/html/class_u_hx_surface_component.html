Detailed Description

Maps tactile information to a texture file on an object.

This component uses a selected uv channel and texture to describe the tactile properties of a surface. The value in the red channel represents the amplitude of the effect created when moving one's hand along the surface of the object. The value in the blue channel represents a constant displacement on a surface, allowing users to represent complex tactile features with simple gemoetry.
