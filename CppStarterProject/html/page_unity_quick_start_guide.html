Unity Quick Start Guide

Start developing with the HaptX SDK. This guide assumes you're either starting with the UnityStarterProject or have just finished the Unity Integration Guide. See Unity Input Quick Reference for default controls.

For a summary of all the features in the plugin see Unity Plugin Summary.

Make an Interactive Object

  1. Choose any 3D object in the scene or drag in one of the basic ones (Cube, Sphere, Capsule, etc.) from the GameObject menu.
  2. Scale the object down to a size that makes it feasible to interact with.
  3. Move the object within reach at the player's starting location.
  4. In the Inspector , add a Rigidbody component.
  5. Verify that the layer of the object is present in the Tactile Feedback Layers , Force Feedback Layers , and Grasp Layers arrays of the HaptxCore Prefab variant associated with the project.
  6. Press Play and try interacting with the object!

Add an Object Haptic Effect

  1. Select any interactive object in the level.
  2. In the Inspector click Add Component and type "object effect".
  3. Select Hx Wave Object Effect.
  4. Make sure the effect component is parallel to the colliders defining the object, or Propagate To Children is checked.
  5. Press Play and try interacting with the object. If you're using real gloves or are simulating the gloves and have the Tactile Feedback Visualizer turned on you should notice the new effect's behavior.
  6. Try playing around with the Frequency Hz and Amplitude N properties of the effect component and see how it feels.

Add a Spatial Haptic Effect

  1. From the GameObject menu select Create Empty .
  2. In the Inspector for the empty game object click Add Component and type "spatial effect".
  3. Select Hx Wave Spatial Effect.
  4. Click Add Component again and type "bounding volume".
  5. Select Hx Sphere Bounding Volume.
  6. Drag the bounding volume you just created into the Bounding Volume field of the spatial effect component.
  7. Position the game object such that the effect's bounding volume is near the player's starting location.
  8. Press Play and try bringing the hand into the effect volume. If you're using real gloves or are simulating and have the Tactile Feedback Visualizer turned on you should notice the new effect's behavior.
  9. Try playing around with the Frequency Hz and Amplitude N properties of the effect component and see how it feels.

Add a Haptic Primitive

  1. In Assets , navigate to Haptx → HapticPrimitives and drag one of the prefabs located there into the scene.
  2. Press Play and try interacting with the new object.

Haptic Primitives have built-in state behavior and event functions that make them extremely powerful for developing advanced interactions. See the prefab named NutAndBolt for an example of an advanced Haptic Primitive interaction. For more information see Unity Haptic Primitive Summary.

Don't have hardware to test with?

That's OK! The plugin comes equipped with the ability to use a VR controller to simulate a real HaptX Glove (see Simulated vs. hardware). You can even get a sense for how your interactions will feel on real hardware using the plugin's haptic feedback visualizers:

  • Tactile Feedback Visualizer
  • Force Feedback Visualizer
