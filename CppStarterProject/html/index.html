HaptX SDK Main Page

The HaptX SDK integrates with HaptX Gloves G1 and gives developers the tools they need to create haptics-enabled content.

For new users

Read the Getting Started page to learn about HaptX Gloves G1 and the HaptX SDK.

Adding haptics to a Unity or Unreal project is easy:

  1. Follow the steps in the Unity or Unreal Integration Guides to add our plugin to your project.
  2. Visit the Unity or Unreal Quick Start Guides and start building your first interaction.

Developing a custom plugin or standalone application?

  1. Check out the API Overview page to get acquainted with the HaptX API.
  2. Get started with the C++ Starter Project (CppStarterProject) included in the installer.
