Detailed Description

The Haptic Effect class to override when creating effects that operate directly on microfluidic actuators (tactors).

To utilize this type of effect:

  1. Override the HaptxApi::DirectEffect::getDisplacementM() function
  2. Add tactors using HaptxApi::ContactInterpreter::addEffectToTactor()
  3. Call HaptxApi::HapticEffect::start()
  4. Use HaptxApi::ContactInterpreter nominally
