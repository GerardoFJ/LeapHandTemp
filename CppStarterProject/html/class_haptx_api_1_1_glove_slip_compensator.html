Detailed Description

Corrects motion-capture artifacts seen in finger positions when a HaptX Glove slides along a user's hand.

This is accomplished by applying an offset in MCP3 space (under the right conditions) such that the apparent locations of the user's fingertips are consistent with the lengths of their finger bones.

Expected operation:

  1. Instantiate a GloveSlipCompensator for a Glove, providing information about handedness and which user is wearing the Glove.
  2. Call applyToMocapFrame() every time you get a new mocap frame to post-process tracked fingertip locations.
  3. Proceed using the post-processed mocap frame in your application however you would have used the original mocap frame.

Glove slip compensation is applied per-user, per-hand.

Applies Glove slip compensation to a given mocap frame.

Mocap frame is expected to have entries for tracked fingertip locations relative to the tracking origin (MCP3).

Parameters
[out]mocap_frameThe frame to apply slip compensation to.
delta_time_sThe amount of time [s] since the last call to applyToMocapFrame().
aggressiveness_1_sMultiplied by delta_time_s to get LERP alpha. Increase to make slip compensation happen faster.
on_thresholdHow straight the user's fingers need to be for Glove slip compensation to engage. Values should range between [0, 1]. A value of 1 indicates perfectly straight (such that Glove slip compensation will likely never engage), and a value of 0 indicates that Glove slip compensation is always engaged.
Returns
True if slip compensation was successfully applied.
