Detailed Description

An inflatable component of a Panel that conveys tactile feedback.

A Tactor, as a microfluidic actuator, can be linked to a hardware port in software via a Mapping and actuated via the HapticControllerInterface.

Tactors have a position and a direction relative to the Movable that contains them.

The absolute ID of a Tactor is its relative ID plus the relative IDs of all SkinComponents it nests within.
