Detailed Description

Minimal but functional OpenVR wrapper functions that HaptX systems use.

If you need additional functionality, reach out to HaptX at suppo.nosp@m.rt@h.nosp@m.aptx..nosp@m.com or interface with OpenVR directly. See https://github.com/ValveSoftware/openvr/tree/master/src .

◆ getTrackerTransform()

HAPTXAPI_DLLEXPORT Result< Transform > HaptxApi::OpenvrWrapper::getTrackerTransform ( const std::string & serial_number)

Get the current transform of a given hand tracker by serial number.

Note
If able, this function will return the pose from the last call to IVRCompositor::WaitGetPoses(); otherwise, it will return the pose from IVRSystem::GetDeviceToAbsoluteTrackingPose() with a "fPredictedSecondsToPhotonsFromNow" value of 0.0.
It was empirically discovered that world space tracker poses change significantly based on their device role. This function checks hand tracker roles and applies relevant offsets to ensure that does NOT happen. For more information see: https://github.com/ValveSoftware/openvr/issues/1328
Parameters
serial_numberThe serial number of the hand tracker to look for.
Returns
The transform of the hand tracker, or an error code.
