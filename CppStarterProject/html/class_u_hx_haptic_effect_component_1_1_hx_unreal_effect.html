Detailed Description

template<typename hx_effect_t, typename ue_comp_t>
class UHxHapticEffectComponent::HxUnrealEffect< hx_effect_t, ue_comp_t >

A templated wrapper to bridge SDK HapticEffects and UE Haptic Effect Components Requires that hx_effect_t is derived from HaptxApi::HapticEffect, and that ue_comp_t::getEffectMultiplier(hx_info_t) is implemented.
