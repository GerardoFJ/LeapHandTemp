Detailed Description

The class responsible for detecting and managing HaptX devices.

Detected devices are responsible for their own functionality; however, this class may configure relationships between them as needed.

Queries the system for any connected hardware devices and populates relevant lists.

Note
Any devices touched by this function will be attempted to be initialized.
Subsequent calls to this function invalidate any pointers held from previous calls to getMocapSystems() or getAirpacks().
