◆ input_offset_

float UHxCurveStateFunction::input_offset_

The amount by which to offset the input to the curve.

It is 'b' in: y = f(ax + b). The units of 'x' are [cm] on UHxLinearDofs and [deg] on UHxAngularDofs .
