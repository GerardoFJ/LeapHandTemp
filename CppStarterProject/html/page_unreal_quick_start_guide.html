Unreal Quick Start Guide

Start developing with the HaptX SDK. This guide assumes you're either starting with the UnrealStarterProject or have just finished the Unreal Integration Guide. See Unreal Input Quick Reference for default controls.

For a summary of all the features in the plugin see Unreal Plugin Summary.

Make an Interactive Object

  1. Choose any static mesh actor in the scene, or drag in one of the basic ones (Cube, Sphere, Cylinder, Cone, etc.) from the Modes panel.
  2. Scale the mesh down to a size that makes it feasible to interact with.
  3. Move the mesh within reach at the player's starting location.
  4. In the Details panel, check Simulate Physics .
  5. Expand Collision Presets and take note of the value of Object Type .
  6. Verify that the object type value is present in the Tactile Feedback Collision Types , Force Feedback Collision Types , and Grasp Collision Types arrays of the child HaptxCore Blueprint associated with the project.
  7. Press Play and try interacting with the object!

Add an Object Haptic Effect

  1. Select any interactive object in the level.
  2. In the Details panel click +Add Component and type "object effect".
  3. Select Hx Wave Object Effect.
  4. Make sure the effect component is a child of the physics component that represents the interactive object.
  5. Press Play and try interacting with the object. If you're using real HaptX Gloves or are simulating the gloves and have the Tactile Feedback Visualizer turned on you should notice the new effect's behavior.
  6. Try changing the Frequency [Hz] and Amplitude [cN] properties of the effect component to see how it affects the result.

Add a Spatial Haptic Effect

  1. From the Modes panel drag in an Empty Actor.
  2. In the Details panel for the empty actor click +Add Component and type "spatial effect".
  3. Select Hx Wave Spatial Effect.
  4. In the Details panel for the spatial effect component find Bounding Volume and select Hx Sphere Bounding Volume.
    Note
    There is a custom tool for visualizing these bounding volumes that is activated automatically when spatial effects are selected in the editor; however, due to a limitation of the editor it must be restarted after new bounding volumes are created before their visualizations will appear.
  5. Position the actor such that the effect's bounding volume is near the player's starting location.
  6. Press Play and try bringing your hand into the effect volume. If you're using real HaptX Gloves or are simulating the gloves and have the Tactile Feedback Visualizer turned on you should notice the behavior of the new effect.
  7. Try changing the Frequency [Hz] and Amplitude [cN] properties of the effect component to see how it affects the result.

Add a Haptic Primitive

  1. In the Content Browser , navigate to haptx Content → HapticPrimitives and drag one of the blueprint assets located there into your scene.
  2. Press Play and try interacting with the new object.

Haptic Primitives have built-in state behavior and event functions that make them extremely powerful for developing advanced interactions. See the blueprint named HaptxNutAndBolt for an example of an advanced Haptic Primitive interaction. For more information see Unreal Haptic Primitive Summary.

Don't have hardware to test with?

That's OK! The plugin comes equipped with the ability to use a VR controller to simulate a real HaptX Glove (see Simulated vs. hardware). You can even get a sense for how your interactions will feel on real hardware using the plugin's haptic feedback visualizers:

  • Tactile Feedback Visualizer
  • Force Feedback Visualizer
