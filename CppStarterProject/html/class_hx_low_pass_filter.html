Detailed Description

A simple low pass filter.

Instantiate one for every value that you intend to filter. To apply the filter, pass unfiltered values to ApplyFilter() and use the return value or FilteredValue.

Field Documentation

◆ filterStrengthS

float HxLowPassFilter.filterStrengthS = 0.1f

How aggressively nominal values will be filtered (similar to time constant) [s].

Smaller values lead to faster responses but more jitter; larger values lead to slower but smoother responses.
