Unity Integration Guide

Follow these steps to add HaptX functionality to an existing project.

Software prerequisites

  • SteamVR
  • Unity version 2021.3 (other versions are either untested or unsupported)
  • Microsoft Visual Studio 2019 with "Game development with Unity" workload

Notes

If you're starting from scratch, we recommend using the pre-configured UnityStarterProject instead.

Setup steps

  1. Install TextMeshPro and XR Plugin Management from Window → Package Manager → Packages: Unity Registry .
  2. Either install the Mirror by vis2k package via the Asset Store , or copy the Mirror folder from our UnityStarterProject into your project's Assets directory.
  3. Install the SteamVR Unity Plugin package via the Asset Store .
  4. Copy the HaptX Unity Plugin into your project's Assets directory.
  5. Check Edit → Project Settings → XR Plugin Management → Plug-in Providers → OpenVR Loader .
  6. Open or restart your Unity project.
  7. The HaptX Unity Settings Window will open with a list of suggested changes to your Unity project settings. It is highly recommended to press "accept all" unless you have a strong reason not to.
  8. Press Window → SteamVR Input → Save and generate .
  9. Create prefab variants of Assets → HaptX → HaptxPlayer , HaptxHand , and HaptxCore and move them to your project content folder.
  10. Configure the Left Hand Prefab and Right Hand Prefab fields on the HxPlayer script on your HaptxPlayer prefab variant to spawn your HaptxHand prefab variants.
  11. Configure the Local Hands Layer and optionally the Remote Hands Layer fields on the HxHand script on your HaptxHand prefab variant to layers that are reserved for representing players.
  12. Make sure that the layer chosen for Local Hands Layer doesn't collide with itself and that the layer chosen for Remote Hands Layer doesn't collide with itself.
  13. In your scene, create a new GameObject and add a HxSinglePlayer script to it. Assign your HaptxPlayer prefab variant to the HxPlayerPrefab field.
  14. Add an instance of your HaptxCore prefab variant to the scene and configure its Tactile Feedback Layers , Force Feedback Layers , and Grasp Layers fields to include the types of objects meant to elicit these responses.
  15. If you intend to build a multi-user project, configure the Physics Authority Zone Layer field on the HxHand script on your HaptxHand prefab variant to a layer that overlaps with physically simulating objects, but doesn't appear in any of the haptic feedback layer fields of your HaptxCore prefab variant.
  16. You're ready to start developing with HaptX! Check out the Unity Quick Start Guide.
