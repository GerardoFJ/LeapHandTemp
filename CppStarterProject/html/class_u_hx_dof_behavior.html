Detailed Description

The base class for all custom physical behaviors used in UHxConstraintComponents .

DO NOT INSTANTIATE THIS CLASS! Use a child class instead.

To implement a custom behavior inherit from this class and override initialize(), and getForceTorque(). Also override tryGetTarget() if your behavior drives toward positions other than 0.

See the Unreal Haptic Primitive Guide for a high level overview.
