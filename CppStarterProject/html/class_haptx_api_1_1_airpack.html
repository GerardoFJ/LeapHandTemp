◆ addPressureCallback()

virtual Result HaptxApi::Airpack::addPressureCallback ( pressure_callback_t pressure_callback)
pure virtual

Establishes a callback that is invoked when a pneumatic port's set point is believed to have been set.

Parameters
pressure_callbackThe callback to invoke whenever we believe a pressure set point has been set.
Returns
A result indicating the callback was set successfully, or an error code.
Note
It is possible for discrepancies to appear between believed and rendered set points in the case that low-level functions in the AirpackApi block or modify the set points for some reason.

Constructs an internal list of attached peripherals and MocapSystems.

This function must be called before getAttachedPeripherals(), getPeripheralAtSlot(), getMocapSystems() or getMocapSystemAtSlot() will produce meaningful results.

Returns
