Detailed Description

An implementation of HxSpatialEffect that defines the Haptic Effect using a simple sine wave generator. The waveform starts at 0 then increases by default.

◆ inputPhaseOffsetDeg

float HxWaveSpatialEffect.inputPhaseOffsetDeg = 0.0f

The phase that the wave starts at [deg], then continues from there.

For example: an offset of 90 degrees turns a sine wave into a cosine wave.
