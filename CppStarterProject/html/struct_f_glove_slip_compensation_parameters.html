Data Fields

float aggressiveness_1_s {1.0f}
 Multiplied by delta time [s] to get LERP alpha. Increase to make glove slip compensation happen faster.
 
float on_threshold {0.95f}
 How straight the user's fingers need to be for Glove slip compensation to engage. Values should range between [0, 1]. A value of 1 indicates perfectly straight (such that Glove slip compensation will likely never engage), and a value of 0 indicates that Glove slip compensation is always engaged.
