Property Documentation

◆ CurrentPosition

float HxDof.CurrentPosition
get

Get the current position or rotation around this degree of freedom.

Rotations are returned in degrees. For rotations the absolute value might be > 180 if HxAngularDof.trackMultipleRevolutions is true. For rotations, we measure this using a vector projection onto the associated plane. This does not use any Euler angles. This means this function may not do what you're expecting it to do if the constrained object can rotate around more than one axis.
