HxHand.PinchAssistanceParameters Class Reference

Holds the parameters that characterize pinch assistance. More...

Data Fields

float distFarM = 0.02f
 The distance between finger tip and thumb tip to begin adjusting non-thumb fingers [m]. Should always be >= distNearM. Distances are scaled according to the user's hand size.
 
float distNearM = 0.01f
 The distance between finger tip and thumb tip to apply maximum pinch assistance [m]. Should always be <= distFarM. Distances are scaled according to the user's hand size.
 
float effectMag = 1.0f
 A scale applied to the correction when at or nearer than distNearM. If set above 1, the finger may overshoot the thumb in some situations, causing jitter.
 

Detailed Description

Holds the parameters that characterize pinch assistance.
