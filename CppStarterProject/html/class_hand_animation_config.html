Field Documentation

◆ legacyBlendEnd

float HandAnimationConfig.legacyBlendEnd = 0.0f

The forward fingertip position when blending with the legacy algorithm ends.

The normalized forward fingertip position to use the legacy algorithm for accurate positioning. As the fingertip moves forward from this position, it begins to use the natural algorithm. Here, a value of 1.0 represents a finger fully extended forward from the knuckle; a value of 0.0 represents a fingertip vertically aligned with the knuckle, and negative values represent the fingertip behind the knuckle (such as a fist).

◆ legacyBlendStart

float HandAnimationConfig.legacyBlendStart = 0.2f

The forward fingertip position when blending with the legacy algorithm begins.

The normalized forward fingertip position to use the algorithm for more natural looking fingers. As the fingertip moves backwards from this position, it begins to use the legacy algorithm. Here, a value of 1.0 represents a finger fully extended forward from the knuckle; a value of 0.0 represents a fingertip vertically aligned with the knuckle, and negative values represent the fingertip behind the knuckle (such as a fist).
