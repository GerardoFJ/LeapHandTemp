◆ setSimulationState()

Result HaptxApi::Dashboard::setSimulationState ( SimulationState sim)

Sets the active setting for the SimulationState in the Dashboard Note: After using this method, a new call to HaptxSystem::detectDevices is needed to retrieve new versions of an Airpack or other peripherals that are represented by the new simulated status. For example, to get a simulated airpack:

Dashboard dashboard; HaptxSystem haptx_system; haptx_system.detectDevices(); auto airpacks = haptx_system.getAirpacks(); ... dashboard.setSimulationState(SimulationState::AIRPACK); haptx_system.detectDevices(); // Invalidates old airpacks! airpacks = haptx_system.getAirpacks(); // Simulated airpack

Parameters
simThe new setting to apply
Returns
An error code, if any.
