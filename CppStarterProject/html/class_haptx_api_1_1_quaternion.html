◆ isFunctionallyEquivalent()

HAPTXAPI_DLLEXPORT bool HaptxApi::Quaternion::isFunctionallyEquivalent ( const Quaternion & other,
float tolerance = 0.0001f ) const
nodiscardnoexcept

Whether this quaternion and another are functionally the same or not within a given tolerance.

Some quaternions can have very different internal representations but represent the same rotation. For example, fields can differ by a minus sign in some cases. This function recognizes such quaternions as being functionally similar despite their disparate representations.

The tolerance considers the independent effect of each rotation on the same set of unit vectors. If all pairwise comparisons of the tip positions of transformed vectors differ by less than the tolerance, the Quaternions are considered to be functionally equivalent.

Parameters
otherThe other quaternion to compare this one to.
toleranceThe tolerance with which to perform comparisons.
Returns
True if they are functionally the same within the given tolerance.
