Computes finger joint angles for an entire hand based on tracked fingertip locations.

This algorithm favors natural finger appearance over strict positional accuracy.

Parameters
gloveWhich Glove to compute finger joint angles for.
configThe hand animation configuration to use for this animation frame
mocap_frameExpected to contain fingertip locations relative to the middle finger metacarpophalangeal joint (MCP3) tracking origin. For any fingertip locations that are missing, the finger will be animated sticking straight out.
avatar_profileProfile containing finger length data for the animated avatar.
[in,out]anim_frameComputed joint angles are added to this AnimFrame.
Returns
True if joint orientations for each finger joint are inserted.
