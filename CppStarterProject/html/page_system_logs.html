System Logs

Describes System Log files.

System Log messages

A System Log message is created at runtime whenever a noteworthy event occurs in the HaptX SDK.

Some messages are simply informational and require no action. Those that have severity ERROR or WARNING typically require some action to restore proper system behavior. See Logging::Severity for more information.

By default, DEBUG-level logging is not performed, because DEBUG logs are very verbose. To enable DEBUG-level logging, change the View → Debug Log setting in the HaptX Dashboard.

System Logs

All messages recorded during runtime are summarized into text files within %HAPTX_SDK_DATA%\Logs\System known as System Logs. Each filename contains the time stamp of when the file was created.

Each line in the log file follows the same format. Table 1 describes what each column in the file means.

Timestamp Severity Message
Format YYYYMMDDTHHmmss±ZONE LEVEL: log message string
Example 20240325T182102-0700 INFO: Successfully opened log file
Table 1. System Log output format.

Note
Any line that starts with whitespace is a continuation of the log message on the previous line.

Debug builds of your project may also include filename and line-number information in the log file.

Log messages

SDK clients can 'hook' into the logging system to output system-log messages to another message-sink of their choosing. See:

  • Logging::registerOutput
  • Logging::unregisterOutput
  • Logging::LogWriter
