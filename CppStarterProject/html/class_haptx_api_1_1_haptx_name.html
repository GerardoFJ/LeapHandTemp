Detailed Description

A wrapper for a std::string that provides convenient hashing functions.

Calling getHash() will generate a hash for the string if the hash does not yet exist. The hash can be generated during construction by invoking the correct constructor, which will slightly increase construction time and slightly reduce runtime costs.

HaptxNames are NOT case-sensitive.
