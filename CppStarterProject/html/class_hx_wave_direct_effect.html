Detailed Description

An implementation of HxDirectEffect that defines the Haptic Effect using a simple sine wave generator. The waveform starts at 0 then increases by default.

The phase that the wave starts at [deg], then continues from there.

For example: an offset of 90 degrees turns a sine wave into a cosine wave.
