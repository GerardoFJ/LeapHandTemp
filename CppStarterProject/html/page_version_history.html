Version History

A summary of SDK changes across each release.

HaptX SDK 3.0.3

October 23, 2024

Detailed changes

  • HaptX Dashboard improvements
    • The Dashboard will now prompt you to upgrade your device firmware if it is older than the version shipped with the SDK.
    • The Dashboard's status-bar icon for the gloves will now show a 'progress spinner' while a USB connection is in progress.
    • Fixed a hang in the Wireless Setup wizard that occurred in certain error scenarios.
    • Fixed a USB-disconnection-detection issue that caused problems when physically disconnecting USB devices.
  • SDK improvements
    • Added support for HTC Vive Ultimate Trackers.
  • Plugin improvements
    • (Unity) Added support testing projects without a VR headset attached.
    • (Unreal) Fixed an issue that caused packaged builds to crash on startup if any animation was present.
  • Other changes
    • Fixed an issue in the CppStarterProject that prevented the MocapFrame from updating properly.
    • SDK now includes Airpack firmware version 2.3.0.

HaptX SDK 3.0.2

August 18, 2024

Highlights

  • The HaptX Dashboard now includes a Firmware Update wizard that can be used to update the firmware on either the HaptX Airpack or HaptX Gloves. See the HaptX Dashboard guide for details.

Detailed changes

  • HaptX Dashboard improvements
    • The HaptX Dashboard now includes a Firmware Update wizard.
    • The Wireless Setup wizard now has progress bars for long-running steps.
    • References to gloves in 'Slot 1' and 'Slot 2' have been replaced with 'Port L' and 'Port R', to match the labels printed on the physical HaptX Airpack.
    • The About dialog includes current firmware version information for attached gloves.
    • Fixed the black 'flash' when the Dashboard was first launched.
    • Improved performance of the Collected Data dialog.
  • SDK improvements
    • New HandAnimationHelpers::applyPinchAssist() function to generalize the pinch-assist functionality from Unity and Unreal Engine plugins, reducing code duplication and allowing pinch assist to be used outside of those plugins.
  • Plugin improvements
    • (Unity) Fixed Unity calibration offsets to match the documentation.
    • (Unity) Unity no longer throws a critical error when using only a single glove.
    • (Unity) The Unity Starter Project now embeds HaptxApi.dll in its Assets folder. As a result, users no longer need to have HaptxApi.dll in their PATH for Unity projects modeled off the starter project.
  • Other changes
    • The HaptX SDK is now bundled with the latest firmware versions for both the HaptX Airpack and HaptX Gloves.
    • Fixed a tactor-routing issue in the hardware definition for the left extra-large glove that caused incorrect tactors to fire on one of the palm panels.

HaptX SDK 3.0.1

July 26, 2024

Note
Once you install the HaptX SDK 3.0.1, existing SDK client applications compiled against a previous version of the SDK need to be recompiled against SDK 3.0.1 in order to continue functioning with the updated runtime components.

Highlights

  • The HaptX Dashboard will try to detect gloves when they are plugged in—without having to run an SDK client application—and they will be immediately displayed in the Hardware Visualizer upon detection. See the HaptX Dashboard guide for details.
  • Many usability improvements and bugfixes.

Detailed changes

  • HaptX Dashboard improvements
    • The HaptX Dashboard detects gloves as they are plugged in.
    • The Hardware Visualizer window now has a context menu.
    • The Debug Log window context menu is now full-featured.
    • The context menu for external applications logs is now full-featured.
    • You can now set the 'log level' for SDK client applications, either via the View → External Applications menu or the context menu.
    • The Tracker Pairing window is now resizable.
    • Changes to the Dashboard's toolbar to enhance usability.
    • The Wireless Setup wizard handles failure conditions more robustly.
    • The Wireless Setup wizard no longer reboots Airpacks with firmware 2.1.0 or higher.
    • Fixed a bug in the Hardware Visualizer that sometimes caused tactors to be positioned incorrectly in the display.
    • The Dashboard will now emit an error message if you try to launch a second Dashboard from a different version of the HaptX SDK.
  • Plugin improvements
    • New 'pinch assistance' function makes it easier to grasp small objects.
    • "Legacy" hand animation parameters were updated to apply blends per finger-length, rather than the absolute forward position.
    • Unity: Small tweaks to some of the physics parameters on the HaptxHand prefab to resolve issues with 'rubbery' fingers and contact damping.
    • Calibration offsets are now independently configurable between the thumb and other fingers, and are laterally mirrored when applied to the left hand.
  • Other changes
    • The installer will now prompt to overwrite the CppStarterProject if you have an existing copy.
    • Fixed a crash in the User Profile Utility if the %HAPTX_SDK_RESOURCES% environment variable was incorrectly set.
    • Fixed an issue that sometimes caused the Mocap Visualizer to not start properly when launched from the Dashboard.
    • Tracker pairing now uses case-insensitive comparisons for serial numbers.
    • Miscellaneous documentation updates to improve accuracy and readability.

HaptX SDK 3.0.0-beta.0

March 31, 2024

HaptX SDK 3.0.0-beta.0 is a preview of the third generation of the HaptX SDK, which is designed for HaptX Gloves G1.

It represents a significant evolution from prior HaptX SDK versions and includes many new features and optimizations requested by our customers.

Highlights

  • The HaptX development team focused on simplifying and clarifying the connection between software and hardware. The new HaptX Dashboard utility now manages connections with HaptX Gloves G1, providing an intuitive hardware status interface and unifying several functions that needed separate applications in our prior SDK generation, such as hardware-visualization, and device simulation.
  • The HaptX API now supports high-frequency tactile feedback through Haptic Effects, leveraging the capabilities of our newest Airpack hardware to communicate impacts and textures more effectively than before.
  • Both our Unreal and Unity plugins now support the reading of tactile details directly from a texture, offering developers a convenient mechanism to tune the feel of virtual objects without modifying model geometry. (See specific Unreal or Unity references to learn more.)
  • An improved hand animation algorithm prioritizes natural finger appearance while maintaining positional accuracy.
  • Under-the-hood optimizations to the HaptX SDK enable applications to run more efficiently.
  • And much more! Please see the changelog at the end of this update for a detailed list of improvements.
Note
This beta release of the HaptX SDK is a software-only release; it is not compatible with HaptX Gloves G1 hardware, or with legacy DK2 hardware. Hardware compatibility will be added in a future release. In the meantime, we offer this beta version to help developers get acquainted with the new SDK features and begin building their next haptic experience.

We welcome your feedback! Please contact HaptX Customer Support with questions, comments, or suggestions.

Detailed changes

  • Introduction of the HaptX Dashboard
    • Live status display of connected hardware
    • Consolidated the the old Hardware State Visualizer into the Dashboard; other utilities such as the Mocap Visualizer and User Profile Utility are still external, but available from the Dashboard's menus
    • Significantly improved rendering responsiveness of the new Hardware Visualizer relative to older Hardware State Visualizer utility
    • Guidance for associating trackers with gloves
    • Wireless setup process for mobile Airpack usage
    • Live log-views for running SDK-client processes
    • Convenient access to on-disk log files and documentation
  • Improvements to motion capture and hand animation
    • Introduced AlternateHandIk algorithm that improves realism of finger motion
    • Hand animation finger angle bounds
    • Support for magnetic motion tracking of the wrist
    • WorldTransformCalculator simplifies process of getting a hand position from a MocapFrame
    • API better accommodates hand tracking methods that don't rely on SteamVR
    • If no user profile is loaded, the size of the attached glove will be used to generate an approximate temporary profile
  • Improvements to grasping
    • Ability to ignore weak grasp score contributions
    • Ability to destroy grasp constraints in the Unity plugin (to match preexisting Unreal-plugin feature)
    • General logic and tuning improvements
  • Improvements to haptic feedback
    • Support of high-frequency feedback via new varieties of Haptic Effects and the introduction of the VibroClip interface
    • Ability to add haptic surface textures to objects via UHxPhysicalMaterials (in the Unreal plugin) or HxPhysicalMaterials (in the Unity plugin)
    • Force-feedback passthrough feature in the simulation-engine plugins allows force feedback to activate when objects without force feedback are pressed against objects that have force feedback enabled
    • Trace radius exposed as a property of UHxPatchComponent / HxPatch classes
    • Addition of cylindrical bounding volumes for spatial effects
  • More developer-friendly HaptX API
    • Improved C++ standards compliance
    • Utilization of C++ attributes, such as [[nodiscard]], where applicable, to catch potential API usage errors
    • More consistent subscription to the rule of five , providing convenient and efficient operations for moving and copying objects
    • Enum values can be converted to strings with HaptxApi::toString
    • Consolidation of return codes into a single HaptxApi::ReturnCode enum
    • Use of HaptxApi::Result for more consistent error handling
    • Utilization of more consistent language for analogous concepts across interfaces
    • More consistent labeling of variables and functions with appropriate physical and geometrical units
    • Introduction of strong typing for certain types that are easily transposed or otherwise misused
    • Replacement of old SystemLogger interface with more flexible HaptxApi::Logging
    • Restored some documentation inadvertently omitted from generated documents
  • More developer-friendly simulation engine plugins
    • Revised tactile feedback visualizer communicates high-frequency tactile actuation
    • Added warning when an object effect lacks a collider
    • Introduced more practical sliders and clamps on certain plugin settings
    • Improved tooltips in both simulation engine plugins
    • Improved organization of HaptX constructs in the Unity plugin
    • Resolved "unsupported enum type" errors in the Unity editor
    • Added generated documents for Unity plugin documentation
    • Improved documentation coverage of Unreal Blueprints
  • Improvements to procurement and representation of Glove objects
    • Major refactoring of Peripheral class and related structures
    • New TrackerMount structure exposes mounting locations on gloves and replaces need for explicit definition of attached trackers, making the interface much more flexible
    • Consolidation of simulated-peripheral database with hardware-definition database; simulated motion capture now uses same files used to represent real gloves
    • Files describing glove sensors and actuators can now be updated between SDK releases
    • New hardware definitions describing gloves within the HaptX Gloves G1 generation
  • General documentation updates
    • New HaptX Dashboard guide
    • Existing guides have been updated to reflect new features
  • Miscellaneous changes
    • Updated the Unreal Starter Project, Unity Starter Project, and C++ Starter Project
    • The C++ Starter Project (CppStarterProject) is now built with CMake
    • User profiles are now encrypted at rest; user profiles created in older versions of the SDK will need to be recreated
    • Many optimizations and bugfixes
    • The static libraries have all been consolidated into HaptxApi.lib
    • A PDB file is now available for the dynamic library to aid debugging
    • Better logging of glove details when hardware definitions are loaded

Renamed interfaces

Customers who are beginning with code from HaptX SDK 2.1.0 will observe that several interfaces have been renamed. These include but are not limited to the following:

  • AirController → Airpack
  • Retractuator → ForceActuator
  • HyleasSystem → MocapSystem
  • HyleasSensor → MocapReceiver
  • HyleasSource → MocapTransmitter
