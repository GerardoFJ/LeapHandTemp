ROS Node Summary

An overview of the features of our ROS nodes.

Topics

The following topics provide ways to interact with our ROS nodes.

/HxMocapDataRaw

This topic posts HxMocapData messages at a rate of node_update_rate_hz. The non-tracker transforms are located relative to the motion capture transmitter.

/HxMocapDataWorld

This topic posts HxMocapData messages at a rate of node_update_rate_hz. All transforms are located relative to the world.

/HxAirpackInput

This topic accepts HxAirpackInput messages representing the haptic actuation to render on the Airpack.

Note
If you do not post at least one message to this topic every airpack_timeout_ms milliseconds, you will experience haptic interruptions as the node believes it has lost contact with the Airpack.

Services

The following service provides a way to get the state of the hardware when the node was started.

/HxHardwareInfo

Sending an empty request to this service will prompt a response containing a HxHardwareInfo.

Parameters

The following parameters control aspects of the node's behavior and can be changed at runtime.

airpack_timeout_ms

This double represents how many milliseconds without a new message on /HxAirpackInput constitutes a "timeout", meaning that the node will stop rendering the last haptic input it received. By default this value is set to 500.0.

node_update_rate_hz

This int represents the rate at which the node will post mocap information to /HxMocapDataRaw and /HxMocapDataWorld, and also the rate at which setpoints received by /HxAirpackInput will update. By default this value is set to 90.

Messages

HxMocapData

HxMocapData describes the position of various locating features on HaptX Gloves G1.

Field Name Field Type Description
ok bool A heartbeat that can be used to validate a stable connection.
receiver_transforms_right HxMocapReceiverData [] A list of locating features' names and transforms for all mocap features on the right hand.
receiver_transforms_left HxMocapReceiverData [] A list of locating features' names and transforms for all mocap features on the left hand.
tracker_transforms_right HxTrackerData [] A list of world space tracker positions and mount ids for the right glove.
tracker_transforms_right HxTrackerData [] A list of world space tracker positions and mount ids for the left glove.
errors HxError [] A list of non-fatal errors produced by the HaptxAPI.
Table 1. Fields of HxMocapData messages.

HxMocapReceiverData

HxMocapReceiverData describes the name and position of a mocap feature of HaptX Gloves G1.

Field Name Field Type Description
name string The name of this locating feature.
transform geometry_msgs/Transform The transform of this locating feature. Its reference frame depends on what topic is being polled.
Table 2. Fields of HxMocapReceiverData messages.

HxTrackerData

HxTrackerData describes the mount id and position of a world-space tracker attached to HaptX Gloves G1.

Field Name Field Type Description
mount_id uint8 The id of the mount this tracker is attached to.
world_transform geometry_msgs/Transform The transform of this tracker relative to the world.
Table 3. Fields of HxTrackerData messages.

HxError

HxError describes a non-fatal erorr encountered by the HaptX API.

Field Name Field Type Description
function string The function that threw the error.
error string A description of the error.
Table 4. Fields of HxError messages.

HxAirpackInput

HxAirpackInput describes a set of haptic setpoints to engage on the Airpack.

Field Name Field Type Description
pressures HxPortPressure [] A list of ports and the pressures we want them to actuate.
Table 5. Fields of HxAirpackInput messages.

HxPortPressure

HxPortPressure identifies a port and the pressure we want to send to it.

Field Name Field Type Description
connector int32 The id of the connector this peripheral is attached to.
port int32 The port of the peripheral we want to engage.
pressure_pa float32 The pressure we want to send to the port.
Table 6. Fields of HxPortPressure messages.

HxHardwareInfo

HxHardwareInfo describes the peripherals attached to the system.

Field Name Field Type Description
peripherals HxPeripheral [] A list of the peripherals that were attached when the node was started.
Table 7. Fields of HxHardwareInfo messages.

HxPeripheral

HxPeripheral describes a peripheral in terms of its ports and tracker mounts.

Field Name Field Type Description
name string The name of this peripheral.
guid string The guid of this peripheral.
force_actuators HxPort [] A list of available force actuators.
tactors HxPort [] A list of available tactors.
tracker_mounts HxTrackerMount [] A list of available tracker mounts.
receiver_ids int32[] A list of mocap receiver ids.
slot int32 The slot this peripheral is connected to.
Table 8. Fields of HxPeripheral messages.

HxPort

HxPort a port that we can use to actuate haptics.

Field Name Field Type Description
port int32 The id number of the port.
max_pressure_pa float32 The maximum allowed pressure for this port.
Table 9. Fields of HxPort messages.

HxTrackerMount

HxTrackerMount describes the mount id and position of a world-space tracker attached to HaptX Gloves G1.

Field Name Field Type Description
parent string The name of the feature that is the parent of this tracker.
mount_id uint8 The id of this tracker mount.
transform geometry_msgs/Transform The transform of this tracker relative to the parent.
