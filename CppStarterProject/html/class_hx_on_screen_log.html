Logs an on-screen message.

Parameters
severityThe severity of the message.
messageThe message text.
durationThe duration the message is to be displayed on-screen. Durations of less than zero are treated as infinite.
messageKeyThe key/ID for this message. Only one message with a given key can display at a time and will replace existing messages with the same key. If negative then a unique key will be chosen automatically.
Returns
The key the message was logged with, or a negative number if something went wrong.
