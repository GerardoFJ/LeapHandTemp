Detailed Description

An implementation of HxObjectEffect that defines the Haptic Effect using a simple sine wave generator. The waveform starts at 0 then increases by default.

The frequency that the signal repeats itself at [Hz].

◆ inputPhaseOffsetDeg

float HxWaveObjectEffect.inputPhaseOffsetDeg = 0.0f

The phase that the wave starts at [deg], then continues from there.

For example: an offset of 90 degrees turns a sine wave into a cosine wave.
