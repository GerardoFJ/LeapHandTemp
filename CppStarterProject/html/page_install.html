Installation

A brief overview of files installed by the installer.

Installation

After downloading the SDK installer (which will have a name like HaptX_SDK_Installer_{version}.exe), simply run it to begin the installation process.

Note
Some of the steps and settings described below will not be available if the SDK is already installed. Should you wish to modify those settings, you must first uninstall the SDK, and then re-install it.

Installation type

Figure 1. The Installation Type dialog.

When setup first launches, you are prompted to choose between a per-user installation ("install for me only" ), or a system-wide installation ("install for all users" ).

The primary distinction between the two is the default locations for the HaptX SDK files.

Warning
Even if you select install for me only , you may need need administrative privileges to complete the installation:
  • If the currently-installed version of the Microsoft Visual C++ Redistributable is missing or out-of-date, the installer will attempt to install or update it; this requires administrative privileges.
  • Installation of the magnetic motion-capture driver (the last step of the setup process) also requires administrative privileges. Note that this step only needs to be performed once per workstation, and can be safely cancelled and skipped on subsequent per-user installations on the same machine.

Install locations

After accepting the HaptX SDK License Agreement, you are next asked to confirm the locations for SDK files (the HaptX API libraries, headers, and documentation, and other supporting files) and for data files that may be modified during runtime. The default locations for these will differ depending on whether you selected a per-user or system-wide installation type .

Select components

You are next presented with the option to select which optional SDK components you wish to install. A minimal installation will include all the libraries and supporting programs necessary to build against the SDK. A more full-featured installation may also include the game-engine and ROS integrations , SDK documentation, and one or more starter projects .

Note
If you choose to install one of the starter projects you will be prompted for a separate installation location for each type. These projects are meant to be modified and iterated on, so they should typically be installed to a user-editable folder (e.g., %USERPROFILE%\Documents ).

Installer Contents

Environment variables

The HaptX SDK installer creates two environment variables, corresponding to the folders you specified during installation:

Variable Purpose
%HAPTX_SDK_HOME% Locates core HaptX SDK headers, libraries, documentation, and supporting files.
%HAPTX_SDK_DATA% Locates files produced and/or consumed by the SDK at runtime, including user profiles and log files.

The default values of these variables differ depending on the installation type :

Variable System-wide default Per-user location
%HAPTX_SDK_HOME% %ProgramFiles%\HaptX\SDK %LOCALAPPDATA%\Programs\HaptX\SDK
%HAPTX_SDK_DATA% %ALLUSERSPROFILE%\HaptX\SDK %APPDATA%\HaptX\SDK

For a system-wide installation, the above are added as system environment variables, enabling all users on the machine to use the HaptX SDK. For a per-user installation, they are added as user environment variables.

HaptX API libraries, headers, and documentation

The HaptX SDK installation provides the HaptX API library in both statically- and dynamically-linked forms.

Library version Installation location
Static (release) %HAPTX_SDK_HOME%\Lib\Release\HaptxApi.lib
Static (debug) %HAPTX_SDK_HOME%\Lib\Debug\HaptxApi.lib
Dynamic (release) %HAPTX_SDK_HOME%\Dll\Release\HaptxApi.dll
Dynamic (release import library) %HAPTX_SDK_HOME%\Dll\Release\HaptxApi.lib
Dynamic (debug) %HAPTX_SDK_HOME%\Dll\Debug\HaptxApi.dll
Dynamic (debug import library) %HAPTX_SDK_HOME%\Dll\Debug\HaptxApi.lib

These libraries provide identical functionality. The release DLL (%HAPTX_SDK_HOME%\Dll\Release ) directory is added to your %PATH% variable during installation.

C++ header files are installed in %HAPTX_SDK_HOME%\Include\HaptxApi . Include these in your project to use the HaptX API. (See API Overview for more information.)

You can find all API documentation in %HAPTX_SDK_HOME%\Documentation after installing the SDK. Alternatively, you can use the desktop shortcut to access this information.

Magnetic motion capture library and headers

For customers whose applications require only magnetic motion capture of the fingers and no haptic feedback, we provide a magnetic motion capture library at %HAPTX_SDK_HOME%\Lib\hyleas_device_driver.lib with C++ headers in %HAPTX_SDK_HOME%\Include\HyleasApi .

Unless you are certain this is what you want, we recommend using the HaptX API library instead.

Plugins for third-party engines

The installer provides plugins for several third-party engines:

  • Unreal Engine (see the Unreal Integration Guide);
  • Unity (see the Unity Integration Guide);
  • ROS 1; and
  • ROS 2.

These plugins are included in %HAPTX_SDK_HOME%\Plugins .

Most users will prefer to begin with a starter project , if available.

Starter projects

Starter projects are bare-bones applications that operate the HaptX API but have no other content. By default, the installer will include starter projects for Unreal Engine and Unity. A C++ Starter Project is also included that demonstrates how to use the HaptX C++ API directly.

The locations of these starter projects can be selected during installation. More information is available in the Unreal Quick Start Guide, Unity Quick Start Guide, and API Overview.

Supporting executables

The HaptX Dashboard, User Profile Utility, and Mocap Visualizer can be found in %HAPTX_SDK_HOME%\Tools . For convenience, desktop shortcuts to commonly used utilities are created upon installation. Also, the HaptX Dashboard is configured to launch when you log in.

Hardware definition templates

The %HAPTX_SDK_HOME%\HardwareDefinitions directory contains files that describe the placement and behavior of physical elements on HaptX Gloves G1. Each hardware definition template contains the information necessary to describe a HaptxApi::Peripheral object. A hardware definition template is loaded automatically by the SDK when a Glove attached to the system requires one. This process is governed by %HAPTX_SDK_HOME%\mocap_hxhw_template_link.bin . Do not modify hardware definition templates or mocap_hxhw_template_link.bin.

Third-party libraries and tools

Certain third-party libraries and tools support operation of the HaptX SDK.

Library/tool Installation location Function
OpenVR %HAPTX_SDK_HOME%\ThirdParty\OpenVR\openvr_api.dll Interfaces with VR hardware, including trackers and controllers
libwdi %HAPTX_SDK_HOME%\ThirdParty\wdi-simple.exe Installs device drivers for HaptX Gloves USB communications
Microsoft Redistributables %HAPTX_SDK_HOME%\ThirdParty\vc_redist.x64.exe Allows operation of programs built using Visual Studio

Third-party licenses

Licenses for third-party software used within the HaptX SDK are collected in %HAPTX_SDK_HOME%\Documentation\licenses.txt .

Mutable data files

The HaptX SDK creates files in %HAPTX_SDK_DATA% to retain certain information between runs. Recorded items include System Logs, user profiles, and tracker pairing information . Do not edit these files manually; instead, use the supplied utilities (e.g., the HaptX Dashboard or User Profile Utility) or SDK APIs (e.g., UserProfileDatabase ).
