The operations are performed T * R * S, which is logically equivalent to applying scale, then rotation, then translation.

◆ transformDirection()

Vector3D HaptxApi::Transform::transformDirection ( const Vector3D & direction) const

Transform the given direction by the transform.

Operates on the vector as if the transform were being applied to a face the vector is normal to. The output direction will have the same length as the input direction.

Use this for normal vectors and angular velocity vectors.

directionThe direction to transform.
