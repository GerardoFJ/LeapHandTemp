Detailed Description

The Haptic Effect component to override when creating effects that are generated via contact with objects.

Extend this component and override the getEffectMultiplier() function and the vibro clips generated in onStart to create your own object-based Haptic Effects. Add your child component to your GameObject and call start() when ready.
