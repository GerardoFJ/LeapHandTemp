Unity Troubleshooting

Troubleshooting guide for the HaptX Unity Plugin.

If you're having a problem not mentioned here, or if you have one of these problems but none of the listed solutions help you, please contact HaptX Support at suppo.nosp@m.rt@h.nosp@m.aptx..nosp@m.com.

Avatar hands are not visible or disappear once project starts

Make sure your VR controllers/trackers are on and being tracked by SteamVR. If they are on but not being tracked, ensure they are within view of the lighthouse base stations. If that doesn't resolve the problem, try restarting SteamVR, re-pairing the trackers in SteamVR, and restarting the game engine.

One or more visualizers don't turn on

If you're trying to toggle a visualizer using input hotkeys, try finding the relevant property on your HaptxHand Prefab or HaptxCore Prefab and toggling it manually instead. If that works, you may not have the input key for that visualizer configured. The settings for the input key should be just below the manual toggle checkbox in the editor.

Keywords: trace, tactile feedback, force feedback, grasp, mocap

The trace visualizer doesn't sense objects or doesn't work as expected

On your HaptxCore Prefab, check to make sure the Tactile Feedback Layers property includes the layer of the object you're trying to feel.

Make sure the object you're trying to feel has Collider s that are accurate to its visual mesh.

Keywords: sample, ray, raycast, raytrace

I don't feel tactile feedback / the tactile feedback visualizer doesn't sense objects

First turn on the Trace Visualizer, and make sure tracing is functioning correctly. If it does not, refer to the Unity Integration Guide for further guidance.

On your HaptxCore Prefab, check to make sure the Enable Tactile Feedback property is true. Also check to make sure its Tactile Feedback Layers property contains the layer of the object you're trying to feel.

Make sure that each HxPatch's Tactor Parameters properties and each HxHand's Body Parameters properties are configured with values similar to their defaults.

Make sure that your object doesn't have a HxPhysicalMaterial Script script with the Disable Tactile Feedback property set to true.

I don't feel force feedback / the force feedback visualizer doesn't sense objects

On your HaptxCore Prefab, check to make sure the Enable Force Feedback property is true. Also check to make sure its Force Feedback Layers property contains the layer of the object you're trying to feel.

Make sure that your object doesn't have a HxPhysicalMaterial Script script with the Force Feedback Enabled property set to false.

It's difficult to pick up objects / grasping isn't working / the grasp visualizer doesn't sense objects

On your HaptxCore Prefab, verify the following properties:

  • Enable Grasping is true
  • Grasp Layers contains the layer of the object you're trying to grasp
  • Grasp Threshold property is not large
  • Grasp Friction is large
  • Grasp Friction Combine Mode is reasonable

See property documentation and defaults in editor for recommended values.

When using VR controllers to simulate gloves, be gentle when pulling the trigger to perform gestures. If you pull too hard you can generate extremely strong forces in game, which would cause objects to pop out of your grasp. This is less of a problem on HaptX hardware because our force feedback system stops your fingers from passing through solid objects.

Make sure that your object doesn't have a HxRigidbodyProperties Script on it with the Grasping Enabled property set to false.

Keywords: grasp, grab, grip, pick up, slip, fall, drop, tight, loose

The hands or fingers crumple on objects if I press too hard

Like all physically-simulated objects, the hand model may respond erratically to extreme forces. Attempting to push the virtual hand through solid objects or constrain it in an unusual manner may cause it to deform. This is expected behavior. There is nothing to prevent someone using the simulated motion capture system or the HaptX Gloves G1 hardware from pushing their controllers, hands, or fingers through a solid virtual object.

To mitigate this behavior you can try the following changes:

  • On your HaptxHand Prefab the parameters related to Corrective Teleportation may be of interest.
  • On your HaptxHand Prefab try lowering the Configuration → Linear Drive → Position Spring and/or Configuration → Linear Drive → Maximum Force parameters.
  • Navigate to Edit → ProjectSettings → Time and reduce Fixed Timestep to 0.011 or less.
  • Increase Rigidbody Solver Iterations or Rigidbody Solver Velocity Iterations on your HxHands.

Keywords: crumple, crush, bend, break, broken, weird, finger, force, poke

I see errors or warnings appearing in the log that aren't visible on my HMD

It's possible that none of the errors or warnings you're seeing are considered actionable enough to appear in the on-screen log. Only user-critical errors are displayed on the HMD.

Verify that the formatting settings in Window → HaptX are reasonable for your viewport size and camera setup and on-screen logging is enabled, and that your HMD's camera is tagged as MainCamera in your level.

If you're playing in the editor, messages will only be visible when the Game window is in focus.

I see warnings related to missing scripts when I play in the editor

Some resources may be corrupted if a project fails to compile the first time it is opened after the HaptX Unity plugin is installed. In the editor, navigate to Window → HaptX and they will be re-generated.

My fingers don't track right when the game starts

Connecting to motion tracking hardware requires approximately 1/8 second. During this brief period, hands will not appear and the game engine may hang.

I have performance problems

If you have many HxJoints in the scene, navigate to Window → HaptX and check Indicate Rigidbodies Awake . While this box is checked any Rigidbody objects that are not sleeping will have arrows pointing toward them from above at runtime. This allows you to gauge whether any of your Rigidbody objects are not sleeping when you expect them to be sleeping. (Sleep behavior can be changed globally in the Unity physics settings, or per object with a HxRigidbodyProperties Script.)

I can't touch my fingers together in-game / I can't pick up small objects / my fingertips stick together in-game

The plugin uses compensation system in the hand animation module that accounts for the thickness of the HaptX Glove G1 fingertips when calculating the distance between your fingertips. If you're noticing that when you bring your actual fingertips together your fingertips in-game either have a gap between them or they tend to stick together like magnets, try adjusting HxHand.thimbleCompensationParameters.

My fingers are scrunched up / too straight when not in contact with anything

Try making a flat hand in game. This triggers an automatic correction that gradually adjusts the appearance of your fingers while they're held out straight. See HxHand.gloveSlipCompensationParameters.

I can't feel my Haptic Effect

Make sure that your effect is outputting nominal forces or displacements (see Haptic Effect Tuning).

Make sure that your effects aren't outputting negative values unless you intend to subtract from pre-existing inflation contributions.

Make sure that your effect is playing (HxHapticEffect.StartEffect, HxHapticEffect.IsRunning). Also make sure your effect has a reasonable duration (HxHapticEffect.SetDurationS, HxHapticEffect.SetLooping). It may be the case that it finishes playing too quickly to be felt.

My Haptic Effect is too intense

Make sure that the forces or displacements being generated by your effect are nominal (see Haptic Effect Tuning).

If you have multiple Haptic Effects operating on the same tactor their results will be summed.

I feel my Haptic Effect everywhere

If you are using a HxSpatialEffect with its bounding volume set to null, this is expected behavior. Define a bounding volume if you want to control where this effect applies spatially.

HxDirectEffects are configured by default to apply to all tactors, but you can remove some if desired (HxDirectEffect.RemoveFromCoverageRegion, HxDirectEffect.RemoveFromTactor).

I always feel my Haptic Effect

Make sure your effect has a non-negative duration (HxHapticEffect.GetDurationS, HxHapticEffect.SetDurationS). All durations less than zero are treated as infinite.

Make sure your effect is not set to loop (HxHapticEffect.IsLooping, HxHapticEffect.SetLooping). If a Haptic Effect is set to loop, it will restart back to the beginning of its timeline whenever it has been playing for longer than its duration.
