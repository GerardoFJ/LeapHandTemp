Glossary

Term

Definition

HaptX SDK

Everything contained in the HaptX SDK installer.

HaptX Gloves G1

The world's first gloves with high-fidelity hand and finger motion tracking, tactile feedback, and force feedback.

Tactile feedback

A mode of haptic feedback that displaces a user's skin to recreate the sensation of coming into contact with physical objects.

Force feedback

A mode of haptic feedback that inhibits the motion of a user's joints or applies large-scale gross forces to a user's body in reaction to contacts with physical objects.

Tactor

A HaptX device that actuates tactile feedback on a user; short for tactile actuator.

Force-feedback actuator
A HaptX device that actuates force feedback on a user.

About the HaptX Gloves G1

Figure 1. An early HaptX Glove prototype.

HaptX Gloves G1 enable a user to feel realistic touch sensations in a virtual environment. The gloves render tactile and force feedback using tactors and force-feedback actuators respectively. The gloves are powered by the HaptX Airpack , which contains an air compressor, pneumatic valves, and the electronics to run them. The Airpack connects to a computer over USB or Wi-Fi.

The HaptX SDK and game-engine plugins interpret motion-capture data from the glove and—together with the SDK client software—determines when to actuate the tactile and force-feedback actuators in each HaptX Glove G1.

Developers can use the HaptX API directly for fine-grained control of individual actuators. The SDK also provides Unreal and Unity plugins that gather, interpret, and render tactile and force-feedback sensations based on interactions within the game engines' virtual environments.

Getting Started with the HaptX SDK

Starter projects for Unreal and Unity

The HaptX SDK includes Unreal and Unity starter projects to get you developing right away. These starter projects are already integrated with their respective plugins and come configured with recommended physics-engine and input settings. Using these projects is the fastest way to get started creating haptic content. See the Unreal or the Unity quick start guide for more information.

Unreal and Unity Plugins

The HaptX SDK includes plugins that empower developers to quickly create interactive haptic content within Unreal and Unity. These plugins include tools for building advanced haptic interactions, simulating hardware, and visualizing haptic feedback. See the Unreal or the Unity integration guide for steps to integrate the plugins with an existing project, and the Unreal or Unity plugin summary for more information about key features.

HaptX API and the C++ Starter Project

For advanced users or users who wish to integrate HaptX Gloves G1 with other software, the HaptX API exposes granular control over the hardware. See the API Overview page for more information. The SDK includes a C++ Starter Project as a working example of how to use the HaptX API. We encourage developers to adapt and expand this project to meet their needs.
