User Profile Utility

An executable for creating and loading user profiles.

Function

The User Profile Utility (UPU) facilitates the process of creating and loading user profiles. A user profile links a username to the physical dimensions and aesthetic preferences that affect hand animation and appearance.

Usage

Figure 1. The User Profile Utility Main Window

  1. Start the User Profile Utility by executing %HAPTX_SDK_HOME%\Tools\UserProfileUtility.exe , or from the HaptX Dashboard by selecting File → Launch Application → User Profile Utility .
  2. Follow the on-screen prompts to create, load, edit, or delete a profile as needed.

Run the UPU each time the current user changes. For best results, create or load the new profile before starting your HaptX-powered application. Once the profile has been changed, you may close the UPU.

User profiles are stored on the local machine (in %HAPTX_SDK_DATA%\UserProfileDatabase ).

Profile types

User profiles can be created in either a persistent format or a temporary "demo" format. Important similarities and differences are summarized below.

Property Persistent Demo
Command on main UPU window? CREATE DEMO
Contains username? Yes No
Contains hand dimensions? Yes Yes
Contains aesthetic preferences? Yes Yes
Can be loaded from disk after creation? Yes No
Can be modified after creation? Yes No

Consider using a demo profile when the likelihood is low that the user will use the system multiple times.

Implementation

The User Profile Utility operates the HaptX C++ API directly. Thus, the same actions performed by the UPU can instead be executed by any HaptX-powered application when needed. This may be useful when the nature of the implementation makes it difficult or impractical to run the UPU repeatedly. Consult the documentation for UserProfile and UserProfileDatabase for more information.
