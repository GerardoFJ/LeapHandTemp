Detailed Description

Helpers for text logging operations within a HaptX system session.

By default, a log file is created in the System Log directory (with a filename based on the current time) when the first LOG event occurs. Additional output destinations can be added with the functions in this namespace.

HAPTXAPI_DLLEXPORT Result HaptxApi::Logging::registerOutput ( const std::string & output_name,
std::shared_ptr< LogWriter > writer )

Registers a new output log-writer for log events.

The writers can potentially be called on any thread in response to a LOG event, but only one thread will be running writer functions at a time. Writer functions must not raise any additional LOG events. Writers must be valid until they are unregistered.

Parameters
output_nameAn identifier string used as a key mapped to output.
writerThe log-writer to register.
Returns
True on success, or an error code.
