◆ inputOffset

float HxCurveModelSerialized.inputOffset

The amount by which to offset the input to the curve.

It is 'c' in: y = a * f(bx + c) + d. Units of [m] on HxLinearDofs and [deg] on HxAngularDofs .

◆ inputScale

float HxCurveModelSerialized.inputScale

The amount by which to scale the input to the curve.

It is 'b' in: y = a * f(bx + c) + d. The units of 'x' are [m] on HxLinearDofs and [deg] on HxAngularDofs .

◆ outputOffset

float HxCurveModelSerialized.outputOffset

The amount by which to offset the output of the curve.

It is 'd' in: y = a * f(bx + c) + d. Units of Unity force (or acceleration) on HxLinearDofs and Unity torque (or angular acceleration) on HxAngularDofs .
