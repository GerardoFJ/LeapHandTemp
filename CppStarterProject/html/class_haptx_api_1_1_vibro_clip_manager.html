Given a VibroClip and target frequency, get the periodogram value at the nearest DFT frequency.

Parameters
clipThe clip to analyze frequencies for.
target_hzThe desired periodogram frequency
analysis_block_sizeThe number of vibro samples per analysis block. Increasing the block size increases frequency resolution, but it must not be greater than the size of the clip.
Returns
The periodogram value if successful; INVALID_VALUE if analysis_block_size is 0 or target_hz is higher than possible at the current sample rate; INVALID_MEMORY if block size is larger than the clip.
