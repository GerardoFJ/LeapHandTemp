Unreal Input Quick Reference

A quick reference for all input controls available in the Unreal Plugin. These controls are only accurate if inputs were copied per the Unreal Integration Guide.

Control Description
Controller Trackpad Left/Right Press Cycle through gestures using AHxHandActor
Controller Trigger Analog gesture progression using AHxHandActor
Shift +1 Toggle the Motion Capture Visualizer
Shift +2 Toggle the Trace Visualizer
Shift +3 Toggle the Tactile Feedback Visualizer
Shift +4 Toggle the Force Feedback Visualizer
Shift +5 Toggle the Grasping Visualizer
Shift +8 Toggle the Displacement Visualizer
Shift +9 Toggle the Network State Visualizer
Shift +0 Toggle the Contact Damping Visualizer
W , A , S , D , Q , Z Translate offset using UHxOffsetTunerComponent
Numpad: 8 , 4 , 2 , 6 , 0 , . Rotate offset using UHxOffsetTunerComponent
Numpad: - Reset offset using UHxOffsetTunerComponent
