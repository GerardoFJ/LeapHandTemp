Detailed Description

A model that maps outputs (scaled and offset) to inputs (scaled and offset) as defined by an arbitrary AnimationCurve.

This is a very flexible model that can be used to describe almost any continuous function (in theory). In practice its usefulness is constrained by the editor tool used to create AnimationCurves.

When designing curves that you intend to re-use, it is highly recommended that the functional region be described across -1 and 1 on both axes. This makes scale parameters very intuitive to use.

See the Unity Haptic Primitive Guide for a high level overview.
