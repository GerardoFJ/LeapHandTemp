Detailed Description

Allows for the association of haptic properties on a per-object basis.

See the Unreal Plugin Guide for a high level overview.

Note
Note that while most of these parameters can be changed at runtime, some of them will not be reflected on previously registered objects unless AHxCoreActor::registerObjectWithCi() and AHxCoreActorregisterObjectWithGd() are called again with the register_again flag set to true. This is something we plan to streamline in a future release.
